CCIOI 视频生成 API

REST API 接入手册 · 异步任务 · T2V / I2V · TOS 输出

Wan 2.2LTX 2.3OpenSora

1. 基本信息

Base URL：https://www.ccioi.com/api
Content-Type：application/json
鉴权：请求头 X-API-Key: ccioi_xxx，也支持 Authorization: Bearer ccioi_xxx。

API Key 由 CCIOI 超级管理员在“管理员控制台 → 外部视频 API”中创建。密钥仅在创建时显示一次。

2. 创建视频任务

POST /v1/videos/generations，成功返回 HTTP 202。

文生视频 T2V

curl -X POST 'https://www.ccioi.com/api/v1/videos/generations' \
  -H 'X-API-Key: ccioi_your_key' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan-2.2",
    "generation_type": "text_to_video",
    "prompt": "A cinematic spacecraft flying above an alien ocean",
    "width": 1280,
    "height": 720,
    "num_frames": 81,
    "fps": 16,
    "seed": 42
  }'

图生视频 I2V

curl -X POST 'https://www.ccioi.com/api/v1/videos/generations' \
  -H 'X-API-Key: ccioi_your_key' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan-2.2",
    "generation_type": "image_to_video",
    "prompt": "The camera slowly pushes forward, cinematic lighting",
    "image_url": "https://example.com/reference.jpg",
    "width": 1280,
    "height": 720,
    "num_frames": 81,
    "fps": 16,
    "seed": 42,
    "callback_url": "https://example.com/webhooks/ccioi"
  }'

请求字段

字段类型说明
modelstringwan-2.2、ltx-2.3、opensora
generation_typestringtext_to_video 或 image_to_video
promptstring必填，视频描述
image_urlstringI2V 必填，必须是公网 HTTPS 地址
width / heightinteger输出分辨率
num_framesintegerWan 必须满足 4n+1；LTX 最大 481
fpsinteger输出帧率
seedinteger随机种子
callback_urlstring可选，任务结束后 POST 通知，必须是公网 HTTPS

提交响应

{
  "task_id": "4c78...",
  "status": "queued",
  "progress": 0,
  "model": "wan-2.2",
  "video_url": null,
  "thumbnail_url": null
}

3. 查询任务

GET /v1/videos/generations/{task_id}

curl 'https://www.ccioi.com/api/v1/videos/generations/TASK_ID' \
  -H 'X-API-Key: ccioi_your_key'

状态：queued 排队、processing 生成中、completed 完成、failed 失败。

{
  "task_id": "4c78...",
  "status": "completed",
  "progress": 100,
  "model": "wan-2.2",
  "gpu_id": "wan-a100-01",
  "video_url": "https://ccioi.tos-cn-beijing.volces.com/videos/...mp4",
  "thumbnail_url": "https://ccioi.tos-cn-beijing.volces.com/thumbnails/...jpg",
  "error": null
}

4. Webhook

填写 callback_url 后，任务完成或失败时 CCIOI 会向该地址发送一次 JSON POST，请返回任意 2xx。回调体与查询接口响应一致。

5. 错误码

HTTP含义
401API Key 无效或已停用
404任务不存在或不属于该 Key 的账号
422参数不符合模型要求
503服务暂不可用
